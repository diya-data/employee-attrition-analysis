# Employee Attrition Analytics Dashboard

This project analyzes employee attrition data to understand key factors affecting workforce retention.

The dashboard provides insights into employee demographics, attrition trends, salary distribution, and departmental performance.

## Tools Used
Power BI
Data Visualization
HR Analytics

## Dataset
The dataset contains employee information such as department, salary, job role, experience, and attrition status.

## Key Insights
• Attrition rate across departments  
• Salary distribution by job role  
• Age and experience patterns  
• Department-wise employee retention
